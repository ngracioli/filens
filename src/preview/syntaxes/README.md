# Gramáticas adicionais

O Filens carrega estas gramáticas junto com o catálogo padrão do Syntect.
Os arquivos `.LICENSE` contêm as licenças dos projetos de origem.

- [TypeScript, JSX e dotenv](https://github.com/sharkdp/bat/tree/c3fe143626d09b6b276093dc34fc44c51b17a9a9/assets/syntaxes/02_Extra) usam as versões do bat adaptadas de Microsoft/TypeScript-Sublime-Plugin, babel/babel-sublime e zaynali53/DotENV, respectivamente. No Filens, a gramática Babel usa o escopo `source.jsx` e atende JSX e as extensões específicas do Babel. O catálogo padrão continua atendendo JavaScript.
- [TOML](https://github.com/jasonwilliams/sublime_toml_highlighting/tree/f5a57e8bff694a4e6c52a491dae579aabc7427cf) vem da revisão usada pelo bat.
